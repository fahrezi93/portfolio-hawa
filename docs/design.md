# Portfolio Hawa

Brief pengguna menjadi desain yang telah disetujui. Satu halaman editorial hangat untuk peluang kerja dan kolaborasi edukasi. React, TypeScript, Vite; CSS biasa; tanpa backend atau deployment.

Putih tulang, arang, zaitun; serif yang bersahaja dan sans-serif untuk teks. Pembuka asimetris, area potret 4:5, bagian tentang dengan pendidikan, kronologi magang dan delegasi, tiga cerita karya, organisasi ringkas, kontak email. Tidak ada gambar orang rekaan atau dokumentasi pengganti. Fallback potret berupa komposisi tipografi yang jelas dekoratif.

Konten dan aset terpusat. Navigasi jangkar selalu tersedia termasuk ponsel. Fokus terlihat, ukuran sentuh 44 px, reduced motion. Verifikasi sumber lokal sebelum menambahkan detail. Pendidikan memakai frasa netral. Magang selalu dilabeli magang. Informed consent tidak boleh masuk public atau distribusi. Tombol CV hanya tersedia apabila berkas publik terverifikasi.

Validasi: TypeScript, build, tautan dan aset, tinjauan browser pada 375/768/1024/1440 px jika tersedia. Font memiliki fallback lokal. Pengujian tidak memerlukan publikasi.
